# Атлас идей: вероятность и статистика

Интерактивная история идей: 25 карточек, первоисточники, генезис понятий,
ментальные эвристики, математические формулы и воспроизводимые Python-опыты.

Временная ось идёт от настоящего слева к ранним событиям справа. Карточки
открываются справа; область чтения можно расширять.

Графики, шесть GIF и математические шрифты встроены в `index.html`.
Заметки и прогресс хранятся в браузере посетителя. Конспект можно скачать
в Markdown вместе с формулами и источниками.

## GitHub Pages

Источник публикации: ветка `main`, папка `/ (root)`. Файл `.nojekyll`
отключает обработку Jekyll. Сайт работает как статическая страница.

## Исторический и учебный слои

Исторические свидетельства отделены от интерпретаций. Эвристики и графики —
современные учебные формулировки; они не приписываются историческим авторам.

Отображение формул использует KaTeX 0.19.0 по лицензии MIT. Уведомление
содержится в HTML и в `NOTICE.txt`.
