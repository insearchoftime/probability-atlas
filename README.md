# Атлас идей: вероятность и статистика

[Открыть «Архив»](https://insearchoftime.github.io/probability-atlas/)

История начинается внизу, у переписки Паскаля и Ферма 1654 года.
Листайте вверх к нашим дням. В основном маршруте — 18 исторических
и 3 современных остановки; четыре учебные основы доступны отдельно.

Выбран дизайн «Архив»: светлая бумага, крупные архивные листы, портрет
и учебные анимации. Бледное древо показывает положение при прокрутке.
На десктопе год, название и кнопка находятся слева, изображение — справа.
Схема и архивный лист переключаются. Фильтры, поиск и каталог доступны сверху.

Карточка начинается с короткой сути, схемы и одного примера. История,
математический разбор, интерактивные опыты, первоисточники и Python
доступны в отдельных вкладках. Оформление всех элементов синхронизировано.

Прогресс и заметки хранятся в браузере. Конспект можно скачать в Markdown.
Все изображения, графики, анимации и математические шрифты встроены в HTML.
Исторические документы и современные реконструкции подписаны отдельно.

## Публикация

GitHub Pages собирается через `.github/workflows/pages.yml`.
Исходный `index.html` сохранён как базовая версия; актуальная страница
восстанавливается из неё и упорядоченных частей `updates/archive-*.b64`,
затем применяется компактное обновление `updates/layout.patch`.
Части содержат сжатое обновление; перед публикацией проверяется SHA-256
полученного HTML. Старый `updates/atlas.patch` больше не используется.

KaTeX 0.19.0 — MIT; уведомление находится в HTML и `NOTICE.txt`.
